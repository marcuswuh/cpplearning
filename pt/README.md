## 目录说明
**必须包含的目录和文件：**
- build: 构建目录，包含编译生成的文件。
- lib: 库目录，包含项目依赖的库文件。
- src: 源代码目录，包含项目的源代码文件。
- config: 配置目录，包含项目的配置文件。
- scripts: 脚本目录，包含项目的脚本文件。
- tests: 测试目录，包含项目的测试文件。
- docs: 文档目录，包含项目的文档文件。
- .gitignore: Git 忽略文件，指定不需要提交到 Git 仓库的文件或目录。
- README.md: 项目说明文件，包含项目的基本信息和使用说明。
- LICENSE: 许可证文件，包含项目的开源许可证信息。
**任意情况下可选：**
- examples: 示例目录，包含项目的示例代码。
- tools: 工具目录，包含项目的工具文件。
- assets: 资源目录，包含项目的资源文件。
- data: 数据目录，包含项目的数据文件。
- logs: 日志目录，包含项目的日志文件。
- tmp: 临时目录，包含项目的临时文件。
- CONTRIBUTING.md: 贡献指南文件，包含项目的贡献指南和代码规范。
- CHANGELOG.md: 更新日志文件，记录项目的版本更新和变更信息。
**条件可选：**
- Dockerfile(可选): Docker 镜像构建文件，包含项目的 Docker 镜像构建信息。
- docker-compose.yml(可选): Docker Compose 配置文件，包含项目的多容器应用配置。
- deps.yaml: 依赖管理文件，包含项目的依赖信息。
