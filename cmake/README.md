# Overview

基础部分：

| 教程         | 内容                                                         |      |
| ------------ | ------------------------------------------------------------ | ---- |
| simple_demo  | 最简单的示例，文件结构是怎么样的,简单的条件判断、变量的使用、消息打印 |      |
| generate_lib | 怎么构建静态库和动态库 怎么调用静态库和动态库                |      |
| manager_lib  | 管理和调用lib、头文件的好的方式。                            |      |
| find_package | 学会使用基础的系统包查找。                                   |      |
| real_project | 能够管理小型和大型的cpp项目。                                |      |

高级部分：

| 教学              |                                                         |      |
| ----------------- | ------------------------------------------------------- | ---- |
| modern cmake      | 理解现代CMake的正确使用方式，面向目标、可维护、可移植。 |      |
| deep in authority | 深入理解 `PRIVATE`, `PUBLIC`, `INTERFACE` 的含义和区别  |      |
|                   | 能够实现**高级依赖管理**                                |      |
|                   | 项目结构化和模块化。                                    |      |
|                   | 熟练使用**生成器表达式**                                |      |
|                   | 熟练使用**安装、打包与导出**等方式。                    |      |
|                   | 能够实现测试和集成、工具链编译、配置文件使用等。        |      |
